# Exam overview: Claude Certified Architect — Foundations

Read this first. It tells you what you're signing up for, how the exam is structured, and in what order to work through the study material in this folder.

## Format facts

| Fact | Value |
|---|---|
| Credential | Claude Certified Architect – Foundations |
| Number of questions | 60 |
| Time limit | 120 minutes |
| Response format | Multiple choice — 1 correct answer, 3 distractors |
| Exam structure | 4 scenarios drawn at random from a bank of 6 |
| Content domains | 5, each independently weighted |
| Delivery | Online-proctored or at a test center |
| Exam fee | $125 USD |
| Scoring | Scaled score, 100–1,000; minimum passing score 720 |
| Validity period | 12 months from the date the credential is awarded |
| Result reporting | Pass or fail only |

Every question must be answered before you can advance — the platform doesn't let you skip and come back, so don't get stuck re-reading one question for minutes on end. With 60 questions in 120 minutes you have an average of 2 minutes per question; scenario questions read longer than standalone ones, so budget accordingly.

## What the exam actually tests

Each of the 4 scenarios you draw frames a realistic production context (a support agent, a CI/CD pipeline, a research system, and so on — see the six scenario docs in this folder), and the questions attached to it probe your judgment about tradeoffs inside that context, not just recall of facts. Expect "which is the best next step" and "why did this fail" framings more than "define X."

## Registration

Register and schedule through Anthropic Academy. Confirm your identification requirements ahead of time if you choose the online-proctored option (a private room, a working webcam, and a government ID are the usual baseline for this kind of proctoring) — check the current requirements on the registration page before your session, since proctoring vendors change these details from time to time.

## Recommended study order

Work the five domain study guides in this folder in order of scored weight, heaviest first — that's where the marginal hour of study pays off most:

1. **Domain 1 — Agentic Architecture & Orchestration (27%)** — `domain-1-agentic-architecture.md`
2. **Domain 3 — Claude Code Configuration & Workflows (20%)** — `domain-3-claude-code-config.md`
3. **Domain 4 — Prompt Engineering & Structured Output (20%)** — `domain-4-prompt-structured-output.md`
4. **Domain 2 — Tool Design & MCP Integration (18%)** — `domain-2-tool-design-mcp.md`
5. **Domain 5 — Context Management & Reliability (15%)** — `domain-5-context-reliability.md`

After the domains, work through the six scenario docs (`scenario-1-customer-support.md` through `scenario-6-structured-extraction.md`) — each one shows how two or three domains combine inside a single production context, which is exactly how the real questions are framed. Close with `exercises.md` for hands-on reinforcement and the review artifacts (`scope-map.md`, `heuristics-cheatsheet.md`, `glossary-and-synonyms.md`, `easy-to-confuse.md`) for a final pass.

## Sample questions

The official exam guide includes a set of sample questions with explanations. Work through them once you've completed the domain guides — they're a useful difficulty and phrasing calibration, showing you how a scenario framing turns into a concrete multiple-choice question. Treat them as a reference for *what the questions feel like*, not as a question bank to memorize; they are not reproduced here.
