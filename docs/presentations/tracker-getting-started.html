Get started with the tracker

A skill you build a little every day. Follow your path, tick off tasks, and watch yourself level up.

How to use the tracker

  1. 1Open the tracker: mykhailo-melnyk.github.io/ae-tracker/tracker.html
  2. 2Sign in with GitHub — one click. That's your account.
  3. 3Pick your path — Web, Mobile, or Backend — so tasks match your work.
  4. 4Start Level 1 — open the first task and go.
  5. 5Check the box when you finish a task — it saves right away, and it's yours.
  6. 6Found a problem or have an idea? Use the ⚑ Report / suggest link — it comes straight to us.
Build the habit
Use AI on your real work, a little, every day. 15 minutes a day beats one long day a month.
  • Ask AI to explain a file you already know
  • Take one unclear prompt and make it clear
  • Read one change before you accept it

The five levels

L1Understand — read, not write
L2Edit with Review — the goal for most of us
L3Plan & Implement — plan before big changes
L4Orchestrate — tools for the whole team
L5Architecture Partner — question your own ideas
